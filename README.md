# HO 철도모형 디오라마 — 내려받기

HO(1:87)·N(1:150) 축척 철도모형을 3D로 꾸미고 운행하는 Windows 게임의 설치 파일을 올려 두는 곳입니다. 소스 코드는 여기 없습니다.

## 설치

1. [최신 릴리스](https://github.com/ykyyyky55-cmd/rail-diorama-releases/releases/latest)에서 `RailDiorama-<버전>-setup.exe`를 내려받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명이 없는 프로그램이라 뜨는 창입니다.
3. 설치 위치를 고르고 설치합니다. 관리자 권한은 필요 없습니다.

- Windows 10/11 64비트
- 설치한 게임은 켤 때 새 버전을 확인하고, 있으면 받을지 묻습니다. 직접 확인하려면 Alt → 도움말 → 업데이트 확인.
- 설치 없이 쓰려면 `RailDiorama-<버전>-portable.exe`를 받아 바로 실행합니다(자동 업데이트 없음).

## 저장

만든 레이아웃은 `%APPDATA%\RailDiorama`에 저장되고, 업데이트하거나 제거해도 남습니다.
다른 PC로 옮기려면 메뉴 → 내 레이아웃에서 ⬇(내보내기)로 파일을 만들고, 그 PC에서 ⬆ 가져오기를 합니다.
